🎓 Student Management System

The Student Management System is a modern web-based application developed to simplify the management of student information within an educational institution. It provides an efficient, organized, and user-friendly platform for storing, updating, searching, and managing student records in a centralized database.

The system eliminates the need for manual record keeping by offering a secure digital solution where student information can be accessed quickly and accurately. It is designed with simplicity, performance, and scalability in mind, making it suitable for schools, colleges, universities, and training institutions.

✨ Key Features

  • ➤ Add new student records with complete personal, academic, contact, and parent information.
  • ➤ View detailed student profiles in a clean and professional layout.
  • ➤ Edit existing student records anytime.
  • ➤ Delete student records securely.
  • ➤ Search students instantly using Name, USN, Department, Semester, City, or State.
  • ➤ Department-wise filtering and sorting.
  • ➤ Interactive dashboard displaying student statistics.
  • ➤ Export student records as PDF and CSV reports.
  • ➤ Responsive and professional user interface.
  • ➤ SQLite database integration for reliable data storage.

🛠️ Technologies Used

Frontend HTML5, CSS3, JavaScript, Jinja2 Templates
Backend Python, Flask Framework
Database SQLite3
Reporting ReportLab (PDF), CSV Export
Development Tools Visual Studio Code, Git, GitHub

🎯 Project Objective

The primary objective of this project is to provide a centralized, efficient, and reliable system for managing student records while reducing paperwork and improving administrative productivity. The application demonstrates the implementation of CRUD operations, database management, search and filtering, reporting, and responsive web development using the Flask framework.
